# Habit Tracker

A simple habit tracker web app made using HTML, CSS, and JavaScript.

Users can:

* Add habits
* Mark habits complete for each day
* View weekly streaks
* Navigate between weeks
* Save progress using localStorage

## How to Run

1. Download or clone the project
2. Open the project folder
3. Run `index.html` in any browser

You can also use VS Code Live Server.

## Features

* Weekly habit tracking grid
* Add, edit, and delete habits
* Streak counter
* Responsive layout
* Data saved after page reload
* Current day highlight

## Technologies Used

* HTML
* CSS
* JavaScript
